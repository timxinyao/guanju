# 用 AI 协助搭建

Codex、Claude、Cursor 等能读取本地仓库并执行 shell 命令的 agent 都可协助。先在自己的电脑打开仓库，让 agent 读取项目说明；板子接 USB，电脑与设备在同一局域网并有串口访问权限。AI 不需要装在板子上，也不需要为固件配置 OpenAI API key。网页由设备提供，控制逻辑在板上独立运行，网页不是 Codex 服务。

你保管密码并在本地编辑 `firmware/secrets.yaml`，不要把 Wi-Fi 密码、电视 PSK、固件二进制、配置展开输出或私人照片发到聊天或公开。AI 能提出操作，但会出错；烧录前亲自核对设备、端口、接线及将执行的命令，现场校准由人完成。遇到不确定的板子或端口先停下核对，不让 AI 猜。

## 可复制的开场提示

```text
请先读本仓库 AGENTS.md、README 和 docs/getting-started.md，再查看实际固件和脚本。我要在自己的电脑组装并安装观距。先说明计划、识别操作系统和 Python 版本，列出 USB 串口并请我确认实际板子；不要猜板型、针脚或端口。先核对 docs/hardware.md 接线，再只做不连接电视的 radar-observer.yaml。每一步告诉我如何检查结果，未经我确认不要执行烧录或控制电视。不要读取、打印、上传或让我在聊天中粘贴 firmware/secrets.yaml；我会自己在本地填写。不要上传固件、日志或私人照片。
```

按 agent 给出的步骤用数据线连接板子，比对插拔前后的串口列表。请其先编译观察固件，你确认端口后再 USB 上传。观察移动、静止、离开，确认雷达正常；不正常时先核对硬件，不直接尝试正式电视控制。

```text
观察版已由我确认工作。请检查联网观察版的配置和命令，说明怎样由我私下填写 Wi-Fi 与备用热点密码，再在我确认端口后通过 USB 编译上传 radar-network-observer.yaml。不要显示秘密。帮我查如何从路由器或 mDNS 找设备 IP，并说明备用热点不等于接入家庭 Wi-Fi。
```

联网观察成功后，自己在电视菜单启用 IP 控制并设置 PSK，私下填入本地 secrets。确认 Sony 接口兼容性和电视状态，再安装 `tv-trial.yaml`。打开设备网页后，由你在真实观看位置逐步靠近、静止和离开，调整参数并观察误触发；雷达无法识别身份，AI 也无法替代实地验证。

```text
联网观察已确认。请按 docs/getting-started.md 和 docs/usage.md 说明正式版 USB 安装、参数 ready 的验证和现场校准。电视的 IP 和 PSK 我已经自行写入本地文件；不要读取或回显它们。先说明预期行为、暂停条件和恢复画面的方式，再等待我确认才操作。
```

后续更新可让 agent 依据 [维护说明](maintenance.md)先记录意图状态、关闭并确认恢复责任释放，再编译上传；更新后等待参数 ready 并核对原值。不要仅凭命令成功或 HTTP 200 认定运行正常。

## 交接摘要模板

跨会话只分享脱敏事实，别包含地址、用户名、密码、原始日志、构建固件或照片：

```text
系统/版本：
板型及已核对的接线：
当前固件阶段：观察 / 联网观察 / 正式
已确认：串口枚举 / 雷达 / Wi-Fi / 电视接口 / 参数 ready（分别说明）
现象与不含敏感信息的错误摘要：
当前意图状态及是否确认画面已恢复：
下一步计划与需要我现场确认的事项：
```
