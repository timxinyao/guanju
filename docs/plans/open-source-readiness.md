# 开源整理实施计划

## 目标与范围

将已运行的ESP32-C3/LD2410C/Sony电视近距息屏项目整理为可复刻的本地Git仓库，品牌Guanju·观距。GitHub创建/远端/推送由用户另一个agent负责，此任务仅本地。正式目录位于用户Projects；旧日期任务目录及其中秘密、固件与构建缓存保留为私有备份，不纳入仓库。默认MIT，第三方依赖另说明。

## 实施

- [x] 引入可公开源码/图示，参数化个人SSID并提供secrets示例、版本固定、跨平台准备和验证入口、CI及安全说明。
- [x] 硬件复刻：BOM/官方购买入口/型号与排针区别/接线图表/供电/安装方向/外壳/校准/边界。
- [x] 软件复刻：新电脑依赖、Sony兼容与PSK、USB首烧、Wi-Fi与IP、OTA/恢复、参数页面、AI协助示例和操作红线。
- [x] 人类README、AI AGENTS与薄CLAUDE指针、架构/贡献/许可/变更/交接资料。
- [x] 进行文档与代码核对、链接/公开内容与秘密审计、宿主机检查及使用示例secrets的配置验证；不向真实设备烧录。
- [x] 独立全任务审查与本地 Git 交付准备完成；按本地 worktree 流程以审查后的完整提交合入 main 并归档，不设置 remote。实际合入、分支与 tag 状态以本地 Git 为准。

## 验收

新用户仅凭仓库可确认硬件/接线、准备环境、独立填本地秘密、编译/首次USB/后续Wi-Fi更新；不把Sony API适配说成所有电视通用，不把雷达目标说成儿童身份/平面距离；没有家用凭据、个人IP/SSID/路径、日志/固件二进制或1.2GB构建缓存进入Git；原私有工作区保留。GitHub交接写明主分支、验证与未验证项、推送前检查。
