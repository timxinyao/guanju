# 使用与现场校准

正式固件的网页由设备提供。在可信局域网访问 `http://<设备IP>/`，也可试 `http://tv-radar.local/`；地址从路由器已连接设备列表或串口日志确认。它不是账号或云服务，无须电脑常开。网页和控制接口没有访问认证，应限制在可信网络，勿暴露到互联网。

## 看懂状态

首页固定在首屏，滑动不会移动首页；参数设置和调试面板可在面板内滚动。极短横屏时隐藏场景插画和页脚，为操作控件留出空间。

页面的自动功能开关表示用户的 **意图**，不是实际监测的保证。设备启动、电视待机或失联、雷达数据过期/未知、参数未验证等情况会暂停，意图 ON 仍可保留；设备不会唤醒电视。首页保留电视状态、真实场景说明、近距范围和靠近确认时间；右上详情按钮才打开「调试模式」，查看更多健康状态和暂停原因。波纹表示雷达数据新鲜在线，不代表自动息屏正在生效。近、远、无人的人物图仅为示意，不代表儿童身份或准确姿态。

首页的场景说明来自设备状态，不会将未知推测为无人，也不显示猜测的触发倒计时。电视状态短暂未知时，在同一次连接中最多保留上次确认的画面展示 5 秒，持续未知后显示待确认。重复未知不会延长该期限。缓存仅用于页面展示，不影响设备控制、监测或命令是否成功；断线、心跳过期、重新连接或明确的电视通信/命令故障会立即使旧展示失效。背影人物依据新鲜诊断快照中的有效最近距离移动；近端扒柜、远端坐沙发和左右进出均为示意，不代表真实角度、身份、姿态或运动轨迹。图中红区对应已确认的近距阈值，黄色窄带对应离开余量；参数未确认时不显示色带。未知或过期时保留并淡化上次位置，不推断为无人。系统开启降低动态效果时使用静态终点姿态。

`Unknown` 是当前测量无法判定，不等于无人。雷达无人后可能保留上次距离，不能将该数字视为当前有人或准确位置。单雷达不能保证目标角度、身份或坐姿，也存在盲区、遮挡和误报；本项目不能作为儿童安全或防护装置。

开启意图并且电视处于活动、连接新鲜、雷达测量可判定及参数已验证时，近区目标持续达到确认时间才会触发息屏。电视待机暂停监测而不会被唤醒。「恢复画面并停用」按钮（设备 API 为 `Restore Picture`）会关闭自动功能意图并请求恢复；若设备控制造成息屏，也可先关闭自动功能并等待恢复。确认画面和「本次恢复责任」均已恢复/为否；如电视不可达则先排查或使用电视遥控器。

恢复责任 `owned` 仅在运行内存中，断电或重启会丢失；若重启后仍黑屏，用遥控器或网页恢复。不要直接拔电来代替确认恢复。

## 临时暂停

意图开启时，可选择「暂停 10 分钟」或「暂停 30 分钟」。暂停保留开启意图，并仅自动恢复本次负责的息屏；不会唤醒待机电视，也不会认领外部造成的息屏。暂停期间显示「继续监测」，可提前结束暂停。到期或继续后，仍须通过正常的健康与新鲜测量检查，不代表马上执行息屏。剩余时间仅在调试详情中显示设备快照的近似分钟数，首页不自行推算倒计时。

如果遥控器或其他客户端恢复了本次息屏，设备会尊重这次手动改变，等有效的离开近区确认后再允许新的自动息屏。「继续监测」只结束临时暂停，不绕过这项等待。关闭自动功能与临时暂停是不同操作。

## 调整参数

默认近距 150 cm，近距确认 3 秒，雷达无人延时 1 秒、离开确认 1 秒，灵敏度标准。雷达 gate 8 的标称观察区域约 6 m，用于观察近/远/无人，并不是 6 m 内都会触发息屏；自动息屏使用配置的近距门限。实际距离、盲区及误报因环境而变。进入近区使用设定门限 D；已在近区时，当前代码要求有效目标距离超过 D + 20 cm 才释放近区，或确认有效无人，以减少边界抖动。20 cm 是代码中的暂定回差，不是医学或安全距离，也不是网页可调参数。确认时间结束后还需要近期有效测量支持，单次旧读数或只等待时钟不会触发命令。

1. 先让电视正常显示，检查雷达新鲜、电视已连接及参数 `ready`。点击右上参数按钮读取已保存值。标题栏「关闭」不是保存；有未应用修改时，需要选择「继续编辑」或「放弃修改」。应用验证中需等待结果再关闭。
2. 先关闭自动息屏，按下方「引导校准」观察近、远、静坐和无人场景。随后确认环境与参数合适，再开启功能检验实际息屏及恢复；现场保持遥控器可用。
3. 按需要调整近距范围（50–300 cm）、靠近确认和恢复确认；无人延时及灵敏度放在默认收起的「高级设置」。灵敏度越高，细微动作可能更容易被检测，也可能增加误触发。一次少量调整，再实际验证。
4. 点「应用设置」，等待页面显示已验证并保存、重新读到预期值。应用期间监测暂停；设备先恢复本次控制的画面，再写入雷达并逐项回读、完整验证和保存。接受提交或 HTTP 200 并不代表完成；失败、冲突或结果未知时刷新后以设备状态为准，必要时重试或恢复默认。

恢复等待包含雷达无人延时、离开确认和通信时间，并非严格定时。浏览器多个标签页会占用连接，调试时先关掉多余页面。右上刷新按钮会重新加载整个页面；自动重连只是同步状态。

## 调试与引导校准

右上详情按钮打开「调试模式」。首页和调试面板共享诊断快照；页面在前台且连接有效时，以约每秒一次的起始间隔请求 `GET /diagnostics`。它和现有控制请求共用串行队列，同时最多一个诊断请求，不新增 SSE 连接。关闭调试面板后首页仍轮询；切到后台、断线或离开页面会取消诊断请求；繁忙、HTTP 429 或离线时退避重试。多位用户或其他采集客户端共用设备的限流额度，并不能各自保证每秒一份。

「最近目标距离」是有效、新鲜的移动/静止目标类别中最近的近似距离，不是精确位置。无目标、未知或数据过期时显示「—」，不沿用残留距离。展开「测量与设备详情」可查看各类别距离、进入/离开门限、参数审计、配置版本、暂停快照和序号；「最近事件」最多保留 12 条内存记录，重启清空，较早记录会移出。它是有限状态快照和事件，不是全帧、无损的雷达录制。

「引导校准」只在自动息屏已关闭、诊断新鲜时允许开始：

1. 站在希望提醒的近处，预期为近区。
2. 退到正常观看位置，预期为远区。
3. 在观看位置安静坐好，继续观察远区检测。
4. 离开雷达覆盖区域，观察是否报告无人。

每步先站好位置再点「开始观察」或「开始这一步」，移动过程不计入记录。每步至少收集 3 次不同快照后点「记录这一步」，最多保留 30 次。页面汇总符合预期次数、不明确次数和有效距离范围；不会自动推荐一个精确安全距离，也不会应用任何参数。可随时「结束观察」；已记录结果只保存在当前页面，刷新后丢失。后台或关闭调试时不继续采集；设备重启或开启自动息屏会停止这次观察。异常时先检查摆放、遮挡和反射，再到设置小幅调整并重测。这些简短观察不代替实际观看条件下的验证。

## 常见问题

- **没有串口**：换 USB-C 数据线/端口；查看系统端口列表、权限和板卡启动模式。见[入门](getting-started.md)。
- **网页连不上**：确认设备加入 2.4 GHz 家庭网络，路由器未隔离客户端，IP 没变化；mDNS 不可用时用路由器 IP。备用热点不代表已连入家网。
- **电视状态 unavailable / expired**：确认电视开机、同网可达、IP 和本地 PSK 正确、IP 控制已启用，检查型号支持；待机时设备不会唤醒电视。
- **无人仍显示旧距离**：以测距可判定、场景和新鲜状态为准，传感器距离可能残留；`Unknown` 不能推断无人。
- **旁边的人未被识别**：检查安装朝向、遮挡、实际覆盖和灵敏度；单雷达不保证侧面覆盖、身份或坐姿。移动位置并现场测试，不能靠调整参数保证安全。
- **页面不稳定或连接不足**：关闭多余标签和设备页面，再刷新；同时打开的 SSE 连接会消耗设备 socket。
- **手机主屏幕图标仍旧**：移除旧图标，在 Safari 重新加载新版网页后再添加；不同系统的缓存和显示仍需实机确认。
