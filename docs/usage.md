# 使用与现场校准

正式固件的网页由设备提供。在可信局域网访问 `http://<设备IP>/`，也可试 `http://tv-radar.local/`；地址从路由器已连接设备列表或串口日志确认。它不是账号或云服务，无须电脑常开。网页和控制接口没有访问认证，应限制在可信网络，勿暴露到互联网。

## 看懂状态

页面的自动功能开关表示用户的 **意图**，不是实际监测的保证。设备启动、电视待机或失联、雷达数据过期/未知、参数未验证等情况会暂停，意图 ON 仍可保留；设备不会唤醒电视。展开设备详情，检查「实际监测」「雷达数据」「测距可判定」「电视状态」「本次恢复责任」和参数状态。波纹表示雷达数据新鲜在线，不代表自动息屏正在生效。近、远、无人的人物图仅为示意，不代表儿童身份或准确姿态。

`Unknown` 是当前测量无法判定，不等于无人。雷达无人后可能保留上次距离，不能将该数字视为当前有人或准确位置。单雷达不能保证目标角度、身份或坐姿，也存在盲区、遮挡和误报；本项目不能作为儿童安全或防护装置。

开启意图并且电视处于活动、连接新鲜、雷达测量可判定及参数已验证时，近区目标持续达到确认时间才会触发息屏。电视待机暂停监测而不会被唤醒。恢复画面按钮 `Restore Picture` 会关闭自动功能意图并请求恢复；若设备控制造成息屏，也可先关闭自动功能并等待恢复。确认画面和「本次恢复责任」均已恢复/为否；如电视不可达则先排查或使用电视遥控器。

恢复责任 `owned` 仅在运行内存中，断电或重启会丢失；若重启后仍黑屏，用遥控器或网页恢复。不要直接拔电来代替确认恢复。

## 调整参数

默认近距 150 cm，近距确认 3 秒，雷达无人延时 1 秒、离开确认 1 秒，灵敏度标准。雷达 gate 8 的标称观察区域约 6 m，用于观察近/远/无人，并不是 6 m 内都会触发息屏；自动息屏使用配置的近距门限。实际距离、盲区及误报因环境而变。

1. 先让电视正常显示，检查雷达新鲜、电视已连接及参数 `ready`。点击右上参数按钮读取已保存值。
2. 在实际安装位置，让一人从正常观看距离缓慢靠近，观察目标状态及息屏，退出近区并等待恢复；也测试静止、不同位置和无人场景。现场保持遥控器可用。
3. 按需要调整近距范围（50–300 cm）、近距确认、无人延时、离开确认和灵敏度。灵敏度越高，细微动作可能更容易被检测，也可能增加误触发。一次少量调整，再实际验证。
4. 点「应用设置」，等待页面显示已验证并保存、重新读到预期值。应用期间监测暂停；设备先恢复本次控制的画面，再写入雷达并逐项回读、完整验证和保存。接受提交或 HTTP 200 并不代表完成；失败、冲突或结果未知时刷新后以设备状态为准，必要时重试或恢复默认。

恢复等待包含雷达无人延时、离开确认和通信时间，并非严格定时。浏览器多个标签页会占用连接，调试时先关掉多余页面。右上刷新按钮会重新加载整个页面；自动重连只是同步状态。

## 常见问题

- **没有串口**：换 USB-C 数据线/端口；查看系统端口列表、权限和板卡启动模式。见[入门](getting-started.md)。
- **网页连不上**：确认设备加入 2.4 GHz 家庭网络，路由器未隔离客户端，IP 没变化；mDNS 不可用时用路由器 IP。备用热点不代表已连入家网。
- **电视状态 unavailable / expired**：确认电视开机、同网可达、IP 和本地 PSK 正确、IP 控制已启用，检查型号支持；待机时设备不会唤醒电视。
- **无人仍显示旧距离**：以测距可判定、场景和新鲜状态为准，传感器距离可能残留；`Unknown` 不能推断无人。
- **旁边的人未被识别**：检查安装朝向、遮挡、实际覆盖和灵敏度；单雷达不保证侧面覆盖、身份或坐姿。移动位置并现场测试，不能靠调整参数保证安全。
- **页面不稳定或连接不足**：关闭多余标签和设备页面，再刷新；同时打开的 SSE 连接会消耗设备 socket。
- **手机主屏幕图标仍旧**：移除旧图标，在 Safari 重新加载新版网页后再添加；不同系统的缓存和显示仍需实机确认。
